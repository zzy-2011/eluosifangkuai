# 🧱 俄罗斯方块 (Tetris)

经典俄罗斯方块，纯 HTML5 Canvas 实现，**无任何外部图片或依赖**。

## 玩法
- **← →** 移动，**↑ / X** 旋转，**↓** 软降，**空格** 硬降
- 手机：**滑动**移动 / 软降，**点击**旋转
- 填满整行即消除，一次消多行得分更高；每消 10 行升一级、下落加速
- 方块堆到顶部即结束

## 特性
- 7 种标准方块 + 旋转与简单踢墙
- 下一个方块预览、分数 / 消行 / 等级显示
- 键盘 + 触屏双操作，本地记录本局成绩

## 运行
直接用浏览器打开 `index.html`，或启动本地服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
